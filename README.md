# PK Insight Studio

Animated, production-style PK analysis frontend prototype.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## GitHub / Vercel
Push this repository to GitHub, then import it into Vercel. The project is Vite + React and is ready for static deployment.

### Important
The NCA values in the demo are illustrative. For regulated or submission-critical work, connect a validated backend and implement validated algorithms, audit trails, method configuration, QC, security, and regulatory controls before relying on results.
